# Contributing

Thanks for improving the obstacle-avoiding car firmware.

## Development setup

1. Fork or clone the repository.
2. Create a focused branch from `main`.
3. Open `obstacle_avoiding_car.ino` in the Arduino IDE.
4. Select the target board and port, then verify the sketch.

## Validation

Compile for the intended board before opening a pull request. Document the motor driver, distance sensor, pin mapping, power source, and physical test conditions.

## Pull requests

Keep firmware changes focused. Explain movement and safety impacts, include observed serial or hardware behavior, and never commit private network credentials.
